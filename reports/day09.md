## 1. 对照立项

### 1.1 立项回顾

- 课题：行为克隆游戏智能体（腾讯 IEG 课题六），扩展方向为**文本指令**；
- 核心假设：**文本指令能显著提升模型在特定指令任务上的完成率**（带指令 ≥60% vs 不带指令 ≤35%，增益 ≥+25pp）；
- 必做 5 项 MVP（M1–M5），详见立项书。

## 2. 对照方案

### 2.1 最终系统架构（与第 2 天方案一致）

```
游戏视频帧(192×192) ──┐
                      ├─► Open P2P 150M 策略模型 ──► 键盘动作 + 鼠标位移
文本指令(可选) ────────┘          │
                                 ▼
            eval/evaluate.py（按键准确率 / 鼠标相关 / 任务完成率）
                    └──► summarize.py 汇总表
                    └──► record_demo.py 对比录屏
```

- 复用官方：模型、UDS 通信、图像/文本分词器（Gemma）、推理服务器；
- 自研增量：`eval/` 六件套（p2p_client / select_testset / evaluate / run_instruct_experiment / summarize / record_demo）+ 环境部署脚本；
- 关键设计决策均按立项书 3.3 节落地：指令模式启动时固定、评测帧对齐、指令自动判定、测试集隔离。

### 2.2 方案落地情况

- 调用约定（第 3 天）与最终实现一致，无返工；
- 假实现边界全部按约定替换为真实实现（随机权重 → 真实权重，占位判定 → 自动判定规则）；
- 代码均已提交 Git 仓库，`README.md` 含完整启动与评测说明。

## 5. 总结与展望

### 5.1 成果总结

1. 完整跑通 Open P2P 150M 行为克隆模型：环境、推理、评测、演示全链路可复现；
2. 自研评测工具链（`eval/`）产出按键准确率、鼠标相关系数、任务完成率三类可量化指标；
3. 完成"文本指令"扩展实验，验证文本指令对指令型任务的正向增益；
4. 交付：Git 仓库（代码 + 复现 README）+ 指标表 + 对比录屏 + 本报告。

### 5.2 不足与展望

- 未做微调（算力受限）：后续可在 16GB+ 显存上用官方 `train.py` 对指令片段同游戏数据微调，探索进一步提升；
- 未做实时游戏推理：后续可部署 Windows Recap + 双卡方案，实现"人在旁输入指令、AI 实时操作游戏"的端到端演示；
- 指令片段数量较少（2 个）：后续可扩充至更多指令类型（转向并射击、绕障碍等）并引入人类打分。
