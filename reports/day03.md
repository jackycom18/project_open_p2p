## 2. 数据约定

### 2.1 数据集格式

| 数据集 | 用途 | 格式 |
|---|---|---|
| p2p-toy-examples | 主线数据：推理验证、测试集、指令片段素材 | 视频帧（训练分辨率 192×192）+ `annotation.proto` 逐帧键鼠动作标注 |
| p2p-full-data | 按需补充（batch 1–5） | 8,000+ 小时人工标注，分批次下载 |

关键点：

- 人类标注为**逐帧键鼠动作**（键盘事件 + 鼠标位移），可与模型输出**逐帧对齐**；
- 帧分辨率统一 192×192（与 150M.yaml 中 `frame_height/frame_width` 一致），无需重采样；
- 每个片段含起止帧，可裁剪出指令片段（含开始帧与结束帧）。

### 2.2 测试集隔离约定

- 测试集：从 toy 数据中**固定**选取 ≤200 帧（约 1 个连续片段），由 `select_testset.py` 按固定 seed 生成 `testset.json` 并**冻结**；
- 隔离原则：测试片段不参与任何训练/微调/提示工程过程；多次实验使用同一测试集，保证可比。

## 3. 主路径调用约定

主路径（一次评测）如下，约定已固定：

```
select_testset.py → testset.json
        ↓
启动推理服务器 (inference.py, UDS: /tmp/uds.recap)
        ↓
p2p_client.InferenceClient.run(frames)   # 发帧收动作
        ↓
evaluate.py        # 读标注 + 模型输出 → 指标 CSV
        ↓
summarize.py       # 汇总指标表（对照验收线）
record_demo.py     # 对比录屏（M4）
```

### 3.1 推理服务器调用约定（inference.py）

| 参数 | 含义 | 说明 |
|---|---|---|
| `--config config/policy_model/150M.yaml` | 模型配置 | 150M 档 |
| `--checkpoint_path checkpoints/150M/<权重>` | 权重路径 | 先 `--use_random_weights` 验证链路，再换真实权重 |
| `--use_random_weights` | 随机权重模式 | 假实现阶段使用 |
| `--input_text` | 开启文本指令模式 | **必须启动时指定**，运行中不可切换 |

- 服务器监听 Unix Domain Socket：`/tmp/uds.recap`；
- 每帧推理：`get_action(frame, text)`——画面帧 + 当前文本指令一起作为输入，输出 `Action(keys, mouse_action)`；
- 文本指令在**服务器终端**输入，按回车提交，指令持续生效直到更新。

### 3.2 评测脚本调用约定（eval/）

| 脚本 | 输入 | 输出 |
|---|---|---|
| `p2p_client.py` | 帧序列 | 模型动作序列（依赖服务器运行） |
| `select_testset.py` | 数据集目录 | `testset.json`（≤200 帧） |
| `evaluate.py` | testset + 标注 + 模型输出 | 指标 CSV（按键准确率 / 鼠标 r / 任务完成率） |
| `run_instruct_experiment.py` | 指令片段 | 带/不带指令两组完成率对比 CSV |
| `summarize.py` | 多个 CSV | 汇总指标表（对照 ≥55% / ≥0.5） |

指标公式（来自立项书第六节）：

- 按键准确率 = 预测按键集合完全匹配标注的帧数 / 总帧数；
- 鼠标相关系数 `r = cov(X, Y) / (σ_X · σ_Y)`，达标 `r ≥ 0.5`；
- 任务完成率 = 判定完成的片段数 / 指令片段总数。

## 4. 假实现边界

为保证第 4 天环境起步、第 5 天主路径贯通不被真实权重/数据阻塞，明确以下**先假后真**边界：

| 位置 | 假实现 | 换真的时机 |
|---|---|---|
| 模型权重 | `--use_random_weights` 随机权重跑通链路 | 权重下载完成后 |
| 推理服务器 | 无（复用官方，不需要假） | — |
| 测试集 | 先用 toy 数据任意片段跑通脚本 | `select_testset.py` 冻结正式测试集后 |
| 指令判定 | 完成标准先用"按键序列模板"匹配占位 | 指令片段正式设计后替换 |
| 指标 | 先输出占位值验证流程 | 真实评测数据就绪后 |

约定：假实现**只用于打通流程**，任何假数据不得进入最终指标表；正式指标一律以冻结测试集 + 真实 150M 权重为准。
