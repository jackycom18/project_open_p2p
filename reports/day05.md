## 3. 演示脚本（答辩可直接用）

```bash
# 终端 1：启动服务器（带指令模式）
cd ~/open-p2p
uv run elefant/policy_model/inference.py \
  --config config/policy_model/150M.yaml \
  --checkpoint_path checkpoints/150M/<权重文件> \
  --input_text

# 终端 2：评测 + 生成演示
python eval/evaluate.py --dataset <toy数据> --instruction "向左移动" --video-name 192x192.mp4
python eval/record_demo.py --testset testset.json --output demo.mp4
```
